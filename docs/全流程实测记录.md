## 0. 构建、启动、CSRF

```bash
npm run build:server && npm run build:client
./scripts/stop.sh && ./scripts/start.sh        # 后端 :3000 + 网关 :5173
curl -c /tmp/yimu-cookies.txt http://localhost:3000/app/yimu/   # 取 suda-csrf-token cookie
# 后续所有请求带：-b /tmp/yimu-cookies.txt -H "x-suda-csrf-token: <token>"
```

坑：CSRF 校验同时查 header 与 cookie；header 名是 `x-suda-csrf-token`（网关会自动补，直连 :3000 必须手工带），**GET 也要带**，否则 403 "csrf token not found in header/cookie"。

## 5. 自动链：视频 → 配音

drivePipeline 每轮 tick 自动驱动（无需人工干预）：

```bash

→ image succeeded ×8 → 自动新建 video pending ×8
```

- Mock 视频通道升级：不再回传"首帧 PNG 冒充视频"，而是用本机 ffmpeg 把首帧循环 + 静音轨合成为真实可播的占位 MP4（`/uploads/mock/mock-*.mp4`，每段约 32KB，时长=镜头时长），轮询 `mock-` 前缀任务秒级 succeeded；

- 全部就绪 → 状态推进 audio_generating → editing，自动建 edit 任务。

## 本次修复的 Bug

1. **Mock 生成缺口（server/modules/generation/model-gateway.service.ts）**
   - 原本只有 video 有 mock 分支；text/image/tts 无 Key 直接抛 "Provider 未配置 API Key"，任务永远 pending 等 Key，全流程无法走通。
   - 新增：mock 文本（规则剧本 JSON，含题材映射与【一句话创意】motif 提取）、mock 图片（zlib 手写 PNG 占位图）、mock TTS（规则合成 WAV）、mock 视频升级为 ffmpeg 合成真实占位 MP4（此前回传 PNG 冒充视频，合成段会挂）；`testProvider` / providers.service `test` 对 mock 免 Key 直接过。
2. **TTS 回写后镜头永久卡 `generating`（job-worker.service.ts writebackToTarget）**
   - 配音任务开跑把镜头置 generating，纯配音回写不恢复状态；若视频先完成，镜头永远停在 generating。修复：配音回写时若镜头已有 videoUrl 则恢复 ready。
3. **Mock 文案 motif 提取污染**：首版把 prompt 里 JSON 契约/风格块文字带进对白；改为优先取【一句话创意】等输入标记之后的段落、题材按 motif 判定。
