# 神剪 3.20.2 · 运镜关键帧

## 本节点落地
- 数据：`timeline_clips.keyframes JSONB`（迁移 `0033_timeline_clip_keyframes.sql`），关键帧结构 `{time,scale,x,y,rotate,easing}`。
- 纯函数：`shared/timeline-keyframes.ts` 负责规范化、线性/缓动采样、增删、ffmpeg 分段表达式。
- 读写：保存 EDL 时归一化关键帧；读取时原样回填；整组替换走 EDL 撤销/修订账本。
- 预览：`StudioPreview` 按播放头采样 `scale/x/y/rotate`，经 `.pv-media-xf` 包裹层变换视频、图片与流畅档画布。
- 面板：`TimelineKeyframePanel` 支持在播放头添加、逐帧编辑时间/缩放/平移/旋转、定位、删除、清空。
- 快捷键：`⌘/Ctrl+K` 添加关键帧；`Alt+K` 打开面板；帮助矩阵由 todo 改为 ready。
- 导出：ffmpeg `zoompan` 按输出帧插值缩放/平移，`rotate` 用秒变量 `t` 插值旋转；只在该片段有关键帧时插入滤镜。

## 口径
- 关键帧时间 = 片段可见起点之后的秒数；变速后仍是时间轴可见时间，预览与导出一致。
- 平移 `x/y` 取值 `-1..1`，预览用 `-x/scale` 折算，方向与 ffmpeg 裁切窗口一致。
- 旋转四周补黑，不拉伸素材。
- 无关键帧时导出链完全不变。

## 验证
- `npm run db:migrate`：0033 已应用。
- `npm run type:check`：server/client 通过。
- `npm test`：31 套件 / 428 项通过（含 7 项关键帧纯函数）。

## 边界
- 曲线变速（Shift+B）、真复合片段、ASR 仍未接入；本节点不提供假入口。
- 关键帧目前覆盖缩放/平移/旋转，不含透明度与蒙版。
