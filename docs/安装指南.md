# 安装指南

一幕·YIMU AI 短剧工坊支持 Docker / macOS / Linux / Windows 四种安装方式，任选其一即可。

## 前置要求

| 组件 | 要求 | 说明 |
|---|---|---|
| Node.js | ≥ 22 | 所有平台必需；未安装请到 https://nodejs.org 下载 LTS |
| PostgreSQL | 16 | 所有平台必需；Windows 需手动到 EDB 官网安装（见常见问题） |
| Redis | 7.x（可选） | 不装也可运行，相关能力降级为内存实现 |
| 磁盘 | 建议 ≥ 5 GB 可用空间 | 依赖、构建产物与数据库共用 |
| 内存 | 建议 ≥ 8 GB | 前端构建阶段占用较高 |

## 方式一：Docker

```bash
docker compose up -d --build
```

浏览器打开 http://localhost:5173/（须带 `/app/yimu/` 前缀访问，如 http://localhost:5173/app/yimu/，否则白屏）。

## 方式二：macOS

```bash
bash scripts/install-macos.sh  # 一键安装：检查依赖、npm install、初始化数据库
npm run build                   # 构建生产版本（前端构建约 1 分钟）
bash scripts/start.sh           # 启动
```

## 方式三：Linux

```bash
bash scripts/install-linux.sh   # 一键安装
npm run build                   # 构建生产版本
bash scripts/start.sh           # 启动
```

## 方式四：Windows

1. 双击 `scripts\install-windows.bat`（自动检查 Node.js / PostgreSQL、安装依赖、初始化数据库）
2. 运行 `npm run build` 构建生产版本（前端构建约 1 分钟）
3. 双击 `scripts\start-windows.bat` 启动服务
4. 浏览器打开 http://localhost:5173/（须带 `/app/yimu/` 前缀访问，否则白屏）
5. 停止服务：双击 `scripts\stop-windows.bat`

## 常见问题

### 端口 5173 / 3000 被占用怎么办

网关默认监听 5173。先查出占用进程再处理：

- macOS / Linux：`lsof -i :5173`
- Windows：`netstat -ano | findstr :5173` 查 PID，再到任务管理器结束对应进程

如需换端口，修改配置后重启服务即可（配置方式见 docs/操作说明书.md）。

### PostgreSQL 连不上

`scripts/setup.js` 在初始化时会做 TCP 连通性探测，失败会直接报出目标主机 / 端口 / 库名，请按提示逐项检查：

- PostgreSQL 服务是否已启动（macOS：`brew services start postgresql@16`；Windows：到“服务”中启动 postgresql-x64-16）
- `.env` 中的连接信息（主机、端口、用户名、密码、库名）是否与实际一致
- 本机防火墙是否放行了数据库端口

### Windows 下 PostgreSQL 需手动去 EDB 安装

Windows 没有包管理器一键安装 PostgreSQL，请手动下载安装：
https://www.enterprisedb.com/downloads/postgres-postgresql-downloads

安装时请勾选安装命令行工具（含 `pg_isready`），否则 `install-windows.bat` 的检查会失败。安装完成后重新双击 `install-windows.bat` 继续。

### 首次启动慢

- `npm run build` 的前端构建约需 1 分钟（机器配置低会更久），属正常现象，请等待构建完成再启动。
- 首次 `npm install` 下载依赖也需要几分钟，请保持网络畅通。

### .env 密钥说明

- `.env` 由 `scripts/setup.js` 在安装时自动生成，内含数据库密码、JWT 密钥等敏感信息。
- 请勿提交到 Git（已在 `.gitignore` 中忽略），请勿发给他人；建议定期备份。
- 如需轮换密钥，直接修改 `.env` 后重启服务即可生效。
- 绝不在文档、截图或聊天记录中粘贴真实密钥。
