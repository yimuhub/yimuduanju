# 神剪 3.20.5 · 真复合片段

## 数据模型
- `timeline_clips.compound JSONB`（迁移 `0035_timeline_clip_compound.sql`）。
- 复合片段本身是一个 `TimelineClip`，`compound.children` 保存子片段：
  `key / sourceUrl / inPoint / outPoint / offset / speed / volume / reverse / keyframes / transition`。
- 不复制媒体，只保存相对复合起点的偏移。

## 编辑
- `Alt+G`：把同轨**相邻**的至少两个未锁定画面片段收成一个整体；`Alt+Shift+G` 解除。
- 属性条同样有「复合片段 / 解除」入口。
- 复合片段可整体移动、修剪；分割会拒绝并提示先解除（避免子片段被切一半）。
- 解除时按当前 trim 展开，还原为子片段，各自拿到新 id/clientKey。

## 预览与导出
- 预览：`virtualCompoundClip` 按播放头找到命中的子片段，把复合片段虚拟成该子片段，播放器正常换源/seek。
- 导出：`expandCompounds` 在主链和画中画链展开为真实子片段，按复合片段 `inPoint/outPoint` 裁剪，后续 concat/overlay/转场逻辑不变。
- `shared/timeline-compound.ts` 纯函数，单测覆盖命中、虚拟映射、展开与裁剪。

## 边界
- 只支持同轨相邻画面；跨轨嵌套与子片段单独多轨混合尚未开放。
- 复合片段不能再次分割；需先解除。嵌套复合（复合里再复合）不支持。
