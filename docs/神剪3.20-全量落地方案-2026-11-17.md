## 3. 四项核心交互

### 3.1 跨轨拖拽自动开轨

**判定**
1. `dragstart` 记录 `clipId / fromTrack / fromLayer / grabOffset`。
2. `dragover` 用轨道行矩形计算目标 `kind + layer`；同 kind 上下相邻层为候选。
3. 松手时若目标层已有片段且时间区间重叠 → 不覆盖，自动在该层之上插入新层（`layer = max(layer)+1`），原片段不动。
4. 若目标层空闲且区间不重叠 → 直接落入；若跨 kind（画面→音频）→ 拒绝并提示「素材类型不匹配」，不做静默转换。

**轨道排序**
- 显示顺序固定：字幕在上，画面 V1 最下、V2…Vn 向上递增，音频在下。
- `sort_order` 仅用于同 kind 内排序；新增层立即重排并持久化，刷新后不跳动。
- 拖拽后写一条 `agent_edit_ops`/`timeline_revisions`，`summary=跨轨移动`，可撤销/回滚。

**异常**
- 拖拽中源片段被并发删除 → 409 + 刷新，不落半截数据。
- 目标层锁定/隐藏 → 禁止落轨并 toast。
- 超出项目时长边界 → 自动裁到 0 或总时长，记 warning。
- 同一 `clientKey` 重复 → 拒绝并提示体检。

**验收**：4 个画面片段，把第 3 段上拖到 V2 空白处 → 生成 V2 新轨、V1 原片段不变；再拖回 V1 重叠区 → 自动开 V3，不覆盖；刷新后层序一致；撤销恢复原状。

### 3.2 字幕单击进入 / 双击编辑

**状态机**
`idle → selected（单击，定位播放头，只读）→ editing（双击，进入 textarea）→ saving（失焦/⌘Enter）→ saved | conflict | error`

- 单击：选中片段、seek 到起点、右侧属性显示字幕内容；不进入输入态。
- 双击：进入编辑态，暂停自动保存计时器，保留原值快照。
- 保存时机：失焦、`⌘/Ctrl+Enter`、切换片段、播放前；`Esc` 取消并还原。
- 冲突：PATCH 带 `baseVersion`；若版本过期且同片段被改 → 返回 `revision_conflict`，弹「保留我的 / 用最新 / 另存为新字幕」。
- 空字幕：允许清空但保留片段，体检标 warning；连续空片段合并提示。
- 输入法：`compositionstart/end` 期间不触发保存，避免中文半截落库。

**验收**：双击改字 → 失焦保存 → 刷新仍在；另一窗口同时改同一字幕 → 第二次保存出现冲突选项；Esc 还原；中文输入不丢字。

### 3.3 三类素材导入

**来源**
1. 本地电脑：`<input type=file multiple>` + 拖放；视频/图片/音频/GIF；上传后校验可解码（视频 `loadedmetadata`、图片 `decode()`），失败标「不可用」且不可拖入。
2. 其他任务可复用素材：按项目/镜头聚合，只列 `status=ready` 且 URL 可访问的产物；预览确认后入当前项目素材库（复制引用，不复制文件）。
3. 资产包：支持一幕资产包 zip；兼容剪映草稿包时只解析「素材清单 + 媒体文件」，不解析闭源工程结构；无法识别的字段忽略并报告。

**流程**：选来源 → 网格预览（分页/全选/按需勾选）→ 单击预览弹窗（视频可播放、图片可放大）→ 确认入库 → 素材库出现文件夹 → 再拖入时间线。
**文件夹**：`项目名/来源/日期` 三层；跨项目导入生成 `来自-<项目名>` 文件夹；同名追加序号，不覆盖。
**异常**：0 字节、404、跨域失效、格式不支持 → 标灰并给出原因；重复导入按内容 hash 去重；大文件分片上传。

**验收**：本地 3 类文件各 2 个 → 全部入库且可预览；跨项目全选 10 个 → 生成独立文件夹；损坏 mp4 不可选；重复导入不产生重复卡片。

### 3.4 全功能编辑 + 悬浮对话

**布局**
- 左栏保留，支持一键收起（宽度 240px ↔ 0）。
- 中间取消对话区，只保留「预览 + 时间线」，预览/时间线分隔线可上下拖拽，比例持久化。
- 右坞镜头池可左右拖拽调宽；镜头池只预览、不重复底部镜头条。
- 对话入口缩为可拖拽悬浮球，任意位置停靠，点击展开对话；拖拽与点击用位移阈值区分（>6px 为拖拽）。

**Agent 权限**
- 三档：每条询问 / 减少询问 / 完全授权；存项目 `metadata.agentPermission`。
- 完全授权仅对「非破坏性、可回滚」操作自动执行；删除整轨、覆盖工程、花钱生成仍走确认。
- 所有 Agent 写入必须产生修订，支持一键回滚。

**验收**：进入全功能编辑后对话区消失、预览占主区、左栏可收起、悬浮球可拖到四角并展开；完全授权下说「把前 3 段删掉」直接执行且可在历史回滚。

## 4. 对话直剪架构（为什么以前不稳，怎么补）

**不是架构做不到**，而是五个可靠性缺口：

1. **文本覆盖不足**：只依赖分镜台词，缺 ASR；长视频大量段落无索引。
2. **单轮无工具循环**：模型只读一次上下文，不能「查索引 → 选段 → 试算 → 校验 → 再改」。
3. **无修订账本**：失败无法回滚，冲突粒度粗。
4. **无体检**：重叠、空隙、缺源无法在执行前发现。
5. **无计划约束**：模型直接吐操作，未先做目标时长/结构规划。

**升级方案**
- 索引层：台词 + 字幕 + ASR 统一 `transcript_segments`，毫秒级；每个片段有 `sourceShotId`、`startMs/endMs`。
- Agent 层：`plan → act → observe → verify` 循环；工具集：`read_timeline`、`search_transcript`、`propose_ops`、`validate_ops`、`apply_ops`、`rollback`。
- 执行层：所有 ops 先在内存 EDL 试算，跑 `scanTimelineIssues`，blocking 则拒绝并让模型重试；通过后事务落库。
- 并发层：长视频按 30–60s 窗口并行摘要，再全局排序选段；写操作串行，读/分析并行。
- 兜底：模型只给解释时，用确定性 `selectRoughCutRanges` 生成 roughcut（已落地）。
- 权限层：完全授权自动 apply；否则出确认卡。

**能力边界**：语义理解、选段、排序、粗剪、字幕改写可做；镜头美学、节奏感只能逼近，不能宣称等同人工剪辑师。ASR 需外部服务或本地模型，属「需额外服务」。

## 5. 剪映快捷键与功能对齐

已对齐：`E` 分割、`Q` 删左、`W` 删右、`Ctrl/Cmd+B` 分割、`Delete` 波纹删除、`Shift+Delete` 留空隙、撤销/重做、空格播放。
待补：`Ctrl+K/Alt+K` 关键帧、`Shift+B` 曲线变速、`J` 倒放、`~` 音画联动、`P` 主轨磁吸、`S` 预览轴、`I/O` 入出点、`Shift+X` 选区导出、复合片段、轨道锁定/隐藏、字幕样式。
原则：快捷键表只做一套真源，工具栏、状态栏、帮助面板全部读同一表；不出现「面板写 S、实际是 E」的双源。

## 7. 验收标准（商用底线）

- 功能：上述 4 项主流程 + 快捷键表全部可操作，无「点了没反应」。
- 数据：刷新/重启后时间线、轨道层序、字幕、素材文件夹不丢；修订可回滚。
- 冲突：双端同时改同片段必须出现冲突选项，不得静默覆盖。
- 性能：100 片段/30 分钟工程，拖动播放头 ≥ 24fps 代理预览；首屏 ≤ 3s。
- 稳定：连续 2 小时编辑不崩；异常退出后重开可恢复最近修订。
- 导出：整片/选区/封面均可导出；失败有明确原因，不留半成品。
- 桌面：三端安装包可启动、可导入、可导出；CI 产物可下载。

## 8. 诚实评估

**可直接实现**：跨轨自动开轨、轨道排序、字幕状态机、三类导入、文件夹、悬浮球、权限档位、体检/回滚、快捷键补齐、选区导出、封面编辑。

**需额外服务/权限/数据**：ASR（需模型/额度）、跨项目素材（需可访问 URL 与归属校验）、剪映资产包（需用户提供包样本，闭源工程不能承诺 100% 兼容）、桌面三端（需 CI 签名/证书与构建机）。

**暂不能承诺**：与剪映像素级一致的复合片段内部行为、所有闭源工程格式互操作、AI 剪辑达到专业剪辑师审美。替代方案：先保证编辑动作与数据可逆，再用模板/评分规则逼近。
