# 一幕·YIMU AI 短剧工坊 · 操作说明书

> 本地运行地址：`http://localhost:5173/app/yimu/`

---

## 一、启动与停止

### 1.1 一键启动

**方式 A：双击启动（推荐）**
```bash
# 首次使用先赋权（终端执行一次）：
chmod +x scripts/start.command
# 之后在访达中双击 scripts/start.command 即可
```

**方式 B：终端命令**
```bash
# 进入项目根目录后执行
./scripts/start.sh
```

启动脚本会自动完成：
1. 启动 PostgreSQL（Homebrew postgresql@16）
2. 初始化数据库 yimu（建库、建表、种子数据，幂等）
3. 前端生产构建（如缺失）
4. 启动后端 NestJS（端口 3000）
5. 启动本地网关（端口 5173，访问根路径 `/` 会自动 302 跳转至 `/app/yimu/`）
6. 自动打开浏览器

> **首次启动耗时约 1-2 分钟**（需构建前端 + 启动后端），后续启动约 10-20 秒。

### 1.2 停止服务
```bash
./scripts/stop.sh
```

### 1.3 访问
- 浏览器打开：**http://localhost:5173/app/yimu/**
- 后端 API：http://localhost:3000
- 日志：`logs/server.log`、`logs/gateway.log`

## 二、首页（工作台）

1. **开始创作**：点击 Hero 区的「开始创作」或「创作模式」任一卡片
2. **三种创作模式**：
   - **极速模式**：输入一句话 → 全自动完成 90 秒短剧
   - **剧本模式**：上传完整剧本 → AI 智能解析分镜/人物/场景
   - **专业导演模式**：全参数可控，专业级创作
3. **数据看板**：查看创作统计、最近项目、热门模板

## 三、一键创作流程

### 3.1 极速模式（推荐入门）
1. 进入「一键创作」页
2. 选择「极速模式」
3. 输入一句话创意（20-200 字），例如：
   > 「一个雨夜，失忆的插画师在旧书店遇到十年未见的初恋，两人用一本书重新认识彼此」
4. 设置参数：
   - **时长**：90s（推荐）
   - **视频比例**：9:16 竖屏（短剧默认）
   - **画风**：写实仿真人 / 2D 日漫 / 韩漫 / 国漫 / 3D 国风 / 赛博朋克
   - **预算模式**：均衡
5. 点击「开始生成」，进入生成进度页（预计 3-5 分钟）
6. 生成完成后在「我的项目」中查看，点击进入项目工作台

### 3.2 剧本模式
1. 进入「一键创作」→ 选择「剧本模式」
2. 上传或粘贴完整剧本
3. AI 自动解析：分镜、人物、场景
4. 进入后续生成流程

### 3.3 专业导演模式
1. 进入「一键创作」→ 选择「专业导演模式」
2. 全参数可控（时长、比例、画风、预算、导演参数等）
3. 生成流程与极速模式一致，但可精细化控制每个环节

## 四、项目工作台

在「我的项目」点击任意项目，进入项目工作台（13 个标签页 + 3 个全屏画布类页面：无限画布 / 一键成片 / 自由画布 3，共 16 个导航项）：

| 标签页 | 怎么用 |
|---|---|
| **概览** | 查看项目进度、关键指标、最近任务 |
| **剧本** | 查看/编辑 AI 生成的剧本全文（可改可存）|
| **圣经** | 世界观（时代/地域/社会规则/画风/色彩）+ 风格圣经（7 字段），分别独立保存 |
| **人物** | 管理角色列表与形象设定 |
| **场景** | 场景 / 地点真实列表，可创建场景、生成场景图 |

| **导演台** | **三栏导演工作台**（详见 4.3）|
| **时间线** | **多轨道时间线，可拖镜头时长**（详见 4.4）|

| **AI助手** | 8 种智能体对话（项目导演/剧本/分镜/角色/场景/摄影/剪辑/质检），消息真实持久化 |

| **质检** | 查看成片质检报告 |
| **导出** | 导出最终成片 |

### 4.1 无限画布（v5 · Pavo 式交互重构）
> 进入方式：项目工作台 → 点「**无限画布**」标签 → 进入**全屏沉浸式画布**（路由 `/app/yimu/project/:id/canvas`）。
> 本版全站画布按 **Pavo 交互 + 浅白青绿视觉**重构，融合小云雀 @ 引用 / 多会话对话 / 创意助手。

1. **添加节点（双击 / 左侧快捷新建）**：
   - **双击画布空白处** → 弹出「添加节点」面板，可选 **文本 / 图片 / 视频 / 音频 / 角色 / 场景 / 剧本 / 分镜 / 导演台 / 资产 / 备注** 11 种类型
   - 也可用**左侧「画布元素」列表**里每组的「+」快捷新建对应类型
2. **节点即工具箱（核心 · Pavo 式）**：
   - **点击任意节点** → 右侧弹出**该节点类型专属的 AI 工具菜单**
   - 例如文本节点：`自己编写 / 一句话生成剧本 / 文生图 / 文生视频 / 图片反推提示词`；图片节点：`图生图 / 角色四视图 / 场景设定图 / 产品设定图`；视频节点：`首尾帧 / 全能参考 / 局部重生成`；角色节点：`角色设定 / 角色四视图 / 角色出演`…
   - 选一个工具 → 输入提示词（可点「**@ 引用资产**」把画布上的角色/场景/图片资产作为参考）→ 点「生成」
   - 结果作为**新节点分支**落在画布并自动连线，**旧节点保留**（版本对比）
3. **分支创作**：从一个节点可反复拉出多个子节点；某一步不满意可回到该节点换分支重做，旧版本不消失
4. **一键铺开（Harness）**：顶部「**一键铺开**」→ 输入一句故事 → AI 自动拆解出**角色资产 + 场景资产**节点铺满画布，后续可 @ 引用保持一致性
5. **连线（单端口 · 无数输入输出）**：节点**左右各一个「+」**端口，同一端口可连无数条线；悬停连线出现 ✂️ 点击剪断
6. **3D 导演台**：新建「导演台」节点 → 点「打开导演台」→ 在 3D 舞台中拖拽**角色素体**摆位、添加**相机**（平视/俯角/仰角/侧拍）、切换「导演视角/相机视角」→ 点「**导出站位示意图**」把摆位图作为图片节点落回画布
7. **多会话对话助手（小云雀融合）**：
   - 右下角圆形按钮打开；**多会话标签页**（可新建）；导演/编剧/美术/质检 4 Agent 切换
   - 输入 `@` 可引用画布资产；「**创意助手**」提供热点检索 / 爆点解析 / 选题推荐 / 方案输出
   - 回复可「落地为画布节点」
8. **集切换**：顶部 **1/2/3** 按钮切换剧集，**每集独立画布**、独立自动保存
9. **一键整理**：点顶部「一键整理」（快捷键 ⌘⇧F）→ 节点按生产类型自动分列并自适应视图
10. **基础操作**：滚轮缩放 / 拖拽平移 / Shift 多选 / 框选 / MiniMap / 锁定；每集画布自动保存到本地，刷新自动恢复

> 注：旧版「@Agent 指令条 + 六类节点看板」与 v4 即梦式画布已按需求重构为本 v5 Pavo 式画布；后续阶段将加回一键成片流水线、31 种工业节点、三通道 API 真接、数据打通、专业视图。

### 4.2 自由画布 3（Pavo 1:1 复刻 · 当前主推）
> 进入方式：项目工作台 → 点「**自由画布 3**」标签 → 全屏沉浸式画布（路由 `/app/yimu/project/:id/canvas-free3`）。
> **界面、交互、弹窗、配色、动画与 Pavo AI 无限画布 100% 一致**；模型选择弹窗当前为演示模型列表（Agnes 2.0 Flash 等），真实生成走「设置 → 模型服务」配置的三通道 API（火山方舟 / OpenAI 兼容中转 / 自定义 API）。

1. **左上角项目区**：
   - **双击「未命名项目」** 可直接重命名
   - 点「**创建新项目**」新建独立画布
2. **左侧「画布元素」**：实时列出画布上所有节点（文本节点 1 / 图片节点 1 / 导演台节点 1…）；顶部「**全部**」下拉可按类型筛选；点击条目画布自动聚焦对应节点
3. **添加节点（双击空白 / 左右加号 / 底部「+」）**：
   - **双击画布空白处** → 弹出「添加节点」菜单：**文本 / 图片 / 视频 / 音频 / 视频合成 / 导演台** + 添加资源（**上传 / 从资产库添加**）
   - 底部工具栏「**+**」弹出同一完整菜单
   - 点击菜单项即创建节点（新节点出现在双击/点击位置）
   - **点节点右侧「+」** → 在节点右侧弹出类型菜单，选中后**在右侧创建输出节点并自动连线**（源节点 → 新节点）
   - **点节点左侧「+」** → 在节点左侧弹出类型菜单，选中后**在左侧创建输入节点并自动连线**（新节点 → 锚点节点）
4. **大模型对话框（双击节点）**：
   - **双击任意节点** → 画布中央弹出大模型对话框（Pavo 同款）
   - **左下角模型 pill** → 点击弹出「**模型选择**」弹窗（模型列表由后台配置：火山方舟 / OpenAI 兼容中转 / 自定义 API）
   - 底栏右侧：**提示词优化 ✨** / **翻译** / **收藏** / **积分** / **发送**按钮
   - **参考自动联动（核心）**：凡是**左侧连线进来的节点，自动成为该节点的参考**——打开对话框时参考区自动显示上游（如「文本节点 1 · 自动」徽标）；点「**参考**」可再选画布其他节点 / 资产库资产；每条参考可单独移除
   - **风格库**：点「**风格**」打开 16 种风格（国风水墨 / 赛博朋克 / 3D卡通 / 电影感…），每种 = 真实参数包（正向风格词 + 负面风格词 + 色调光影质感 + 参考强度），「应用」后自动写入生成请求
   - **负面提示词**输入框 + **参考强度**滑杆（0-100%），生产可调
   - 文本节点对话框含**富文本工具栏**；图片节点为**图片生成面板**（描述框 + 风格 / 参考 / 比例 9:16 / 分辨率 1K / 预设通用 / 张数 1）
5. **节点「尝试」功能（文本节点）**：`自己编写 / 一句话生成剧本 / 文生图 / 文生视频 / 图片反推提示词`
5. **视频生成面板（Pavo 同款 + 智能模式规则）**：双击视频节点 → 顶部模式选项卡「**文生视频 / 全能参考 / 首尾帧**」（不再显示在节点卡片下方）；风格 / 参考 / 负面词 / 参考强度 + 参数行「**比例 | 时长 | 分辨率**」（9:16 / 4s / 720P，均可下拉切换）；✨ 提示词优化 / 翻译真实调用
   - **三种模式的选择规则（按节点类型判定）**：
     1. **左侧只有文字节点（或没有上游）** → 只能选「文生视频」（文字参考），另外两个按钮置灰并提示「需要图片参考」
     2. **左侧只要有图片节点**（图片还没生成也算）→ 「全能参考」「首尾帧」一定可用，弹窗**默认选中「全能参考」**；选「全能参考」后，左侧全部图片节点自动列为参考图（带「自动」标记），可继续点「参考」从画布加、或点参考图右上角 × 移除，可加多张
     3. **「首尾帧」**：自动把第一张上游图作为首帧、第二张作为尾帧，每个槽位可「从画布选择」「上传本地图片」「取消选择」
   - **描述留空也能发**：全能参考自动生成「根据图片1、图片2…参考画面，生成连贯自然的视频」；首尾帧自动生成「图1是首帧，图2是尾帧，从图1无缝转场过渡到图2」
   - **首尾帧真实链路**：发送时首图作为请求 `image`（首帧）、次图作为 `image_tail`（尾帧）传给视频模型
   - **添加角色（Pavo 同款交互）**：底部工具栏「添加角色」（或左侧角色区「+ 添加」）→ 弹出素体菜单（10 项）→ **把鼠标移到「几何模型」上展开二级菜单**（立方体/球体/圆柱体/环状体/圆锥/棱锥）→ 点击即加入场景（自动命名角色0X、自动配色，可拖拽/Gizmo 变换）
   - **摄像机导演参数（Pavo 同款）**：左栏点「摄像机01」→ 右栏属性：**切换机位**（下拉换摄像机）、**注视目标**（自动=看向场景中心 / 手动坐标=输入注视点 XYZ）、**视野角度 FOV**（滑杆 20-120，实时改变取景）、**相机截图**（当前机位截图 + 截图缩略图历史，点击放大）
   - **模型服务配置**：左侧菜单「设置」→「模型服务管理」→「添加模型服务」→ 填写服务名称、类型、Base URL、API Key → 测试连通性支持三档（**格式校验/请求预览免费**，真实请求才计费）→ 点「获取模型列表」拉取可用模型 → 点击模型旁图标一键填入文本/图片/视频/配音字段 → 保存
   - **一键整理画布（Pavo 同款）**：底部工具栏点「整理画布」（⌥⇧F）→ **立即执行**（节点按连接关系分层排列：无源节点在左、有上游的节点向右递增，同层垂直排列）→ 弹出「是否保留此次整理结果」→ 点「保留」应用新布局，点「还原」恢复整理前位置
   - **3D 导演台旋转手感（Pavo 同款）**：按住左键拖拽 3D 画面旋转视角——速度已调至与 Pavo 相近（约 0.002 rad/px），松手后带**阻尼惯性滑行**（缓慢停下，不会突然停住）；滚轮缩放同样降速。若觉得快/慢，点底部工具栏的**灵敏度按钮**（⚪十字图标）→ 弹层内滑杆 0.2×-2.0× 或预设「慢 / 标准 / 快」即可实时调整旋转与缩放灵敏度
   - **文本节点「自己编写」**：点击后进入富文本编辑框，输入或粘贴任意内容 → 发送**直接保存为节点文本（不经过 AI 生成）**
6. **生成闭环（真实三通道 API）**：对话框输入提示词 → 点「发送」→ 弹窗关闭 → 节点显示进度：
   - **后端已配置 API**（设置 → 模型服务，火山方舟 / OpenAI 兼容中转 / 自定义）→ **真实生成**：文本走 chat/completions、图片走 images/generations（参考图自动上传）、视频走 videos/generations（首帧参考）、音频走 audio/speech；完成后节点显示「**已完成**」+ 真实产物（可预览）
   - **未配置 API Key/Base URL** → 自动降级为演示数据，节点标注「**演示（未配置模型供应商，演示数据。请到「设置 → 模型服务」配置 API）**」，绝不伪装真实
   - **后端未启动** → 自动降级为演示数据，节点标注「**演示（未连接后端服务，演示数据。请启动后端并在「设置 → 模型服务」配置 API）**」，绝不伪装真实
   - 真实调用本身出错（如供应商返回错误）→ 节点显示「**失败**」+ 明确原因
7. **端口连线（左右各一「+」）**：
   - 从节点**右「+」**拖线到另一节点**左「+」** → 蓝色连线生成
   - **点击**「+」→ 弹类型菜单建节点并自动连线（左「+」建输入、右「+」建输出）
   - 从端口**拖线到空白处** → 弹出「添加节点」菜单，新建节点后**自动连线**
   - 悬停连线出现 ✂️ 可剪断
   - **连线即参考**：新节点自动参考所有左侧上游内容
8. **底部工具栏（从左到右）**：
   - **整理画布**：自动排列所有节点（弹确认窗「还原 / 保留」）
   - **画布小地图**：右下角地图（节点色块 + 视口框，点击跳转）
   - **网格吸附**：拖拽节点自动对齐网格
   - **缩放菜单**：放大 ⌘+ / 缩小 ⌘- / 适合屏幕 ⌘0 / 50% / 100% / 800%
   - **撤销 / 重做**
   - **+** 添加节点
   - **历史资产**：本画布产生的全部资产
   - **快捷键**：查看全部快捷键
9. **导演台（3D）—— Pavo 完整版**：
   - 双击建「导演台」节点 → 点节点内「**打开导演台**」→ 进入 **3D 导控台**；左上「×」返回画布
   - **顶部**：「导演视角 / 机位视角」切换；机位视角时中央浮出**摄像机取景预览窗**（跟随所选机位实时渲染）
   - **底部工具栏（Pavo 同款，从左到右）**：
     1. **变换模式**：移动（V）/ 旋转（R）/ 缩放（F）三选一，切换后选中对象脚下 Gizmo 形态变化（箭头 / 圆环 / 方块）
     2. **添加角色**：弹出 **10 种素体**菜单（男性 / 女性 / 宽厚 / 健壮 / 纤细 / 少年 / 儿童 / 二头身 / 群众3×3 / 几何模型），自动配色
     3. **导入全景图**：上传 360° 环境背景图
     4. **导入本地模型**：上传 GLB/GLTF 3D 模型到场景
     5. **添加机位**：直接 +1 摄像机
     6. **选择画幅比例**：自动 / 1:1 / 2:1 / 3:4 / 4:3 / 16:9 / 21:9 / 9:16 共 8 种
     7. **当前视角截图 / 四方位截图 / 十二方位截图**：弹出取景确认窗（缩略图预览）→ 确认后**落回画布为图片节点**
     8. **九宫格辅助线**：构图三分线开关
     9. **全屏**：导演台全屏
   - **左侧对象列表**：角色 / 摄像机分区 + 搜索过滤；每行**眼睛（显隐）/ 锁（锁定）**；「+ 添加」同底部按钮
   - **右侧「属性 / 姿势」面板**：
     - 属性：名称、位置 / 旋转 / 缩放（x / y / z 可输入实时联动）、颜色（角色）、删除选中对象、导出站位示意图
     - 姿势：20 种姿势预设 + 身体（前倾/转身/侧倾）与躯干（前倾/扭转）滑杆，应用到选中角色
   - **3D 场景交互**：点选角色/摄像机（左栏或 3D 中）→ 脚下出现变换 Gizmo：**拖箭头沿轴移动 / 拖圆环绕轴旋转 / 拖方块缩放**；直接拖角色在地面 XZ 摆位；空白拖拽旋转视角；滚轮缩放
   - **六向视图**：视口右上角 X+ / X- / Y+ / Y- / Z+ / Z- 六个按钮一键切视角；左上角三维坐标轴指示器跟随相机
10. **右上角**：积分（200，每次生成扣减）/ 升级 / 幕
11. **基础操作**：滚轮缩放 / 空白拖拽平移；画布自动保存到本地（刷新恢复）

## 五、API 三通道配置（重要）

进入「设置」→「模型服务 / API 配置」，配置大模型与生成通道。

### 5.1 火山方舟 · 推荐
- **类型**：火山方舟（volcengine_ark）
- 需要：火山引擎 API Key（https://console.volcengine.com/ark）
- 配置：
  - API Key：ark-xxxxx
  - 文本模型：doubao-seed-1.6 等
  - 图片模型：doubao-seedream-4.0 等
  - 视频模型：doubao-seedance-2.0 等
  - TTS 模型：doubao-tts 等 + 音色
- 请求格式：volcengine_ark

### 5.2 OpenAI 兼容中转站
- **类型**：OpenAI 兼容中转站（openai_proxy）
- 需要：中转站 baseURL + API Key
- 配置：
  - Base URL：https://your-proxy.example.com/v1
  - API Key：sk-xxxxx
  - 文本/图片/视频/TTS 模型名按中转站支持填写
- 请求格式：openai

### 5.3 自定义
- **类型**：自定义（custom）
- 完全自配 baseURL、Key、模型、格式

### 5.4 设为默认
配置完成后将对应 Provider 设为「默认」，新建生成任务即使用该通道。
支持多 Provider 并存，不同任务可用不同通道。

## 六、常见问题（FAQ）

### Q1：页面打不开 / 白屏？
- 确认先运行 `./scripts/start.sh`
- 确认访问地址是 `http://localhost:5173/app/yimu/`（**必须带 /app/yimu/ 前缀**，平台路由基于该 basename）

### Q2：为什么端口 3000/5173 被占用？
- 说明服务已在运行，直接访问即可；或运行 `./scripts/stop.sh` 后重启

### Q3：PostgreSQL 无法启动？
- 确认已安装：`brew install postgresql@16`
- 运行 `brew services start postgresql@16`

### Q4：生成任务一直失败？
- 检查「设置」中的 API 配置是否正确（Key 是否有效、模型名是否支持）
- 检查网络是否能访问对应 API 服务
- 失败任务可在「项目工作台 → 任务」中点击重试

### Q5：如何重置数据库？
```bash
psql -h localhost -d postgres -c "DROP DATABASE yimu;"
./scripts/start.sh   # 会自动重建
```

### Q6：数据存在哪里？
- 本地 PostgreSQL 数据库 `yimu`，全部业务数据持久化存储

### Q7：想快速看新功能的演示数据？
```bash
# 在项目根目录下，为指定项目填充演示场景/镜头/角色/地点（替换为项目 ID）
node scripts/seed-demo.js <projectId>
```

### Q8：为什么需要通过本地网关（5173 端口）访问？
- 本地网关负责伺服前端静态产物、将根路径 `/` 自动 302 规范重定向至 `/app/yimu/`（避免白屏），并为本机回环请求注入默认开发身份上下文。

### Q9：如何备份数据库？
```bash
./scripts/backup-db.sh   # 生成 backups/yimu-YYYYMMDD-HHMMSS.sql.gz，自动保留最近 7 天
# 定时每天 03:00（macOS，将 $(pwd) 替换为实际项目路径）：
# (crontab -l 2>/dev/null; echo "0 3 * * * $(pwd)/scripts/backup-db.sh >> /tmp/yimu-backup.log 2>&1") | crontab -
# 恢复：gunzip -c backups/<文件>.sql.gz | psql -h localhost -d yimu
```
