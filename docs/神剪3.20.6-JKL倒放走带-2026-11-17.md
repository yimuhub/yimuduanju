# 神剪 3.20.6 · J/K/L 真倒放走带

## 实现
- 播放状态新增 `playDir`（`1` 正放 / `-1` 倒放），主时钟按方向推进：`curT += step * playDir`。
- `J` 倒放、`K` 暂停、`L` 正放；倒放到 0 自动停，不回绕。
- 空格、播放条按钮、镜头池点选恢复正放，避免 J 之后「空格仍倒放」。
- 预览媒体：
  - 视频在倒放时暂停原生播放，由主时钟逐帧反向 seek（浏览器不支持负 playbackRate）。
  - 音频同理；独立音频片段支持 `reverse` 时按 `outPoint - 本地时间×speed` 反向定位。
  - 正放仍走原生 `video.play()`，不牺牲流畅度。

## 验证
- `npm run type:check` 通过。
- `npm test`：32 套件 / 435 项通过。
- `npm run build:client` 成功。

## 边界
- J 目前是 1× 倒放；剪映可连续按 J 加速倒放（2×/4×/8×），本版未做多档倍率。
- 倒放为逐帧 seek，连续播放比正放更吃 CPU；拖动播放头不受影响。
