# 流程重构方案 v2 —— 基于三个对标项目的完整用户流调研

> 调研对象：DramaClaw（dramaclaw/dramaclaw，6.5k★）、火宝短剧（chatfire-AI/huobao-drama）、Toonflow（HBAI-Ltd/Toonflow-app，19.8k★）。
> 调研方式：通读 README / docs / 路由与页面源码 / 流水线编排代码，逐环节还原"新用户进入 → 第一部成片"的完整用户流。
> 结论先行：**三个对标项目没有一个把"全自动一键成片"作为主路径**。它们的共性是"**每一步都有看得见的产物 + 明确的确认门 + 统一的任务中心 + 失败可局部重试**"，全自动只是"确认后段落内自动连跑"。YIMU 目前是反的：确认门只有入口一个（开拍计划），入口之后全自动，但**自动链在首帧图就断了**，后面的环节全部要用户自己发现、自己点，进度还看不到总览。

## ① 三个项目用户流逐环节拆解

### 1.1 DramaClaw（双轨制：流水线 Series + 无限画布 XiaHua，一条资产库）

**首页 = 项目列表**（`frontend/src/routes/_app/index.tsx`，仅"新建项目"对话框 + 项目卡片 + 归档/搜索）。没有对话式首页——创作从"命名一个项目"开始，非常轻（填个名字即建）。

**项目内是固定的流水线步骤页**（`frontend/src/routes/_app/projects.$project/`）：

| 环节 | 页面/路由 | 用户看到什么 | 自动 or 确认门 | 等多久感知 |
|---|---|---|---|---|
| 1 结构化导入 | `ingest.tsx` | 上传/粘贴小说或剧本 → 预览 → 点「开始导入」 | 手动触发；导入是异步任务，页面有日志流（SSE 行），做完自动产出集/角色/场景 | 分章 + LLM 结构化，分钟级；页内实时日志 + "Step 3/3" 收尾兜底 |
| 2 资产库 | `characters.lazy.tsx` 等 | 角色/场景/道具/音色按用途文件夹组织，可逐个生成形象 | 手动逐个/批量 | 图片秒~十秒级，缩略图先占位 |
| 3 集规划+剧本 | `episodes.tsx` / `episodes.$episode/script` | 按集列出；点进单集看剧本 | 分集方案需用户确认；剧本生成有 review-and-repair 循环 | 异步任务 |
| 4 分镜+首帧 | `episodes.$episode/beats` / `sketches` | beat 驱动分镜表 → 分镜图网格，**图池多选**（一次生成多张挑一张） | 每集逐段确认 | 异步 |
| 5 配音 | `audio.lazy.tsx` | 情感化 TTS 逐镜列表 | 批量投递、逐镜可重跑 | 异步 |
| 6 合成导出 | `compose.lazy.tsx` | 整集装配 + 字幕 + 导出资产包 | 手动触发 | 分钟级，任务中心跟踪 |
| 贯穿 | `tasks.tsx`（任务中心） | 所有异步任务：状态/进度/日志/取消/重试/**断点续跑**；排队前先做前置条件校验 | 全自动链的可见性都在这里 | SSE 实时推送（`frontend/src/task-center/stream-client.ts`：EventSource + 指数退避 + 掉线自动降级轮询） |
| 贯穿 | `freezone.lazy.tsx`（虾画无限画布）+ Xia Director agent | 自然语言 → agent 规划 17 节点工作流图 → **用户确认后执行**，节点逐个跑、失败可恢复（`WorkflowRunRecoveryBar`） | agent 提案 → 人确认 → 执行 | 全程 |
| 贯穿 | `assistant.tsx`（Xia Director） | 回答项目问题、推进剧本/分镜任务、检查交付完备度 | 对话即操作 | — |

**关键机制**：
- **每步都有独立界面**，可跳过、可从任意 checkpoint 续跑（README："run them in order, skip steps, resume from any checkpoint"）。
- 任务中心是"全自动"的载体：链式任务都挂在任务中心，用户随时能看到、能 cancel/retry。
- 画布产物可以「commit 回剧集」（`frontend/src/features/freezone/commit/`，先预览影响再提交）——探索与正式生产双轨。
- 首次配置模型只有一步：Settings 粘贴 DC Key（`docs/en/getting-started/quickstart.md`）。

### 1.2 火宝短剧 huobao-drama（最"跟直线走"的 6 步流水线）

**首页 = 项目列表 + 「新建项目」**（`frontend/app/pages/index.vue`）。新建只填三样：剧名、画幅（16:9/9:16，创建后不可改）、画面风格。

**剧集工作台**（`frontend/app/views/drama/episode.vue`，单页 4000+ 行）＝**左侧进度栏 + 四段跑马灯 + 当前阶段大画布**。整条流水线 6 步，每步一个显式按钮，步与步之间是硬确认门（后端有前置校验：`productionBlockMessage` 未满足时下一步直接被拦）：

| 步 | 用户动作 | 门 | 进度呈现 |
|---|---|---|---|
| 1 创建项目 | 填剧名/画幅/风格 | — | 同步 |
| 2 配置 AI（首次） | 设置页「火宝快捷配置」贴一个 Key，一键写入文本/图片/视频三条配置；未配置时全站顶部横幅引导 | 配置前功能禁用 | 横幅自动消失即成功 |
| 3 剧本 | 粘贴小说 → 点「AI 改写」（可选模型/语气）→ 左右双栏对照 → 满意点「保存并进入制作」 | **人工审阅剧本后才进下一步** | 内部 01 原文/02 改写两个子步 |
| 4 资产 | 点「提取」→ 角色/场景/道具清单 → 逐个或批量「生成形象」 | 提取结果可增删改 | 提取是异步轮询（`pollExtractStatus`，刷新页面恢复状态） |
| 5 分镜+视频 | 点「拆分分镜」→ 右侧逐镜检查/微调提示词（`@角色名` 自动映射参考图）→ 顶栏选视频模型/分辨率/时长档 → 「批量生成视频」，失败一键「重试失败」 | 分镜可改完再投；投递前最后确认 | `setInterval` 轮询任务表（`pollVideoGeneration`、`pollVideoPromptBatch`），任务抽屉里看全队列 |
| 6 拼接导出 | 勾选镜头（悬停预览单个视频）→ 「开始拼接」FFmpeg 合成 → 在线播放/下载 → 「标记完成」点亮进度栏 | 勾选即门 | 同步/短轮询 |
| 引导 | 首次进入工作台自动播放 6 步引导（`useTour`，`episode.vue:3464`"沿左侧进度栏走 6 步流水线"） | — | — |

**关键机制**：
- **左侧进度栏是全局唯一的进度叙事**：永远知道自己在哪一步、下一步点哪。这是新用户"停不下来"的核心——没有选择困难。
- 每步产物（剧本/资产/分镜/视频）都在当前页可见可改，改完立即是下一步的输入。
- 失败处理粒度到"单个镜头"，且专门有「重试失败」聚合按钮。
- 4 个 Mastra Agent（script_rewriter / extractor / storyboard_breaker / prompt_generator）严格对应 4 个步骤，用户感知的就是 4 个按钮，Agent 是实现细节。

### 1.3 Toonflow（无限画布 + Agent 逐阶段确认，19.8k★ 的做法）

**首次进入 = `/hello` 引导页**（`apps/web/src/pages/hello/index.vue`）：三选一——登录 TF-Router 一键自动配好全部模型 / 添加私有提供商 / 稍后配置。配置状态持久化（`stores/hello.ts`），完成后永不再见。

**`/home` = 项目列表**：「新建项目」（选本地文件夹）+ 项目卡片（封面/最近打开/打包导出 ZIP/重命名）+ 灵感探索页。

**`/workspace` = 无限画布**（`apps/web/src/pages/workspace/index.vue`）+ 右下角 `floatingAgent.vue`（悬浮 AI Agent）。**没有传统的分页工作台**——剧本、角色、场景、分镜、图、视频全部是画布上的节点（`packages/nodes/`：textNode / imageGenerationNode / videoGenerationNode / audioGenerationNode / director3dNode / frameAnalysisNode 等）。

**流程编排全在 Agent 的 Skill 里**（`packages/skills/v118workflow/SKILL.md`，14 阶段），其铁律写进了提示词：

> 每步执行顺序是：**读已确认输入 → 完成本阶段 → 保存到指定画布 → 回读并检查 → 展示结果 → 等待用户确认**。聊天摘要不能代替画布成果，任务启动不能代替媒体成功。

| 阶段 | 确认门 |
|---|---|
| 0 项目初始化 → 1 来源章节事件 → 2 故事骨架 → 3 改编策略 → 4 逐集剧本 | 每阶段产出到「剧本画布」，**逐阶段确认**；剧本"一集一确认" |
| 5 基础资产提取 → 6 资产图片 | 确认提取清单 → 确认生成方案 → **确认采用图片** |
| 7 导演规划 → 8 衍生资产 → 9 衍生图片 | 逐段确认 |
| 10 分镜表 → 11 分镜面板落点 → 12 分镜图 | 确认数量/时长/连线 |
| 13 视频 | **三个独立确认关口**：提示词/配置 → 生成结果 → 选用与交付 |
| 结构 | 一剧本总画布 + 一资产总画布 + 每集一个制作画布（`项目工作区/画布/分集/第001集.json`），跨画布靠引用节点 |

**关键机制**：
- "每集一个画布"= 天然的进度单位与续作入口；画布本身就是分镜列表+资产库+成片预览。
- Agent 的每一步产物都落成画布节点，**用户永远看得见、摸得着、可手改**；手改后 agent 从"首个未确认阶段继续"。
- 生成节点自带占位/历史，失败重生成不动其他节点（局部重跑天然成立）。

## ③ 重构后的目标用户流（从打开首页到第一部成片）

设计原则（取三家长处）：**入口极简（火宝）+ 步骤有门（Toonflow/DramaClaw）+ 链内自动、链间确认 + 一个总进度叙事 + 任务中心兜底**。

### 流程总览（新用户 → 第一部成片，9 步）

```
S1 首页 hero 输入一句话
S2 开拍计划确认门（保留，加"先看大纲"）
S3 流水线总控页（新）：剧本生成 → ✋门1 → 物化分镜 → ✋门2 → 批量首帧
S4 分镜确认门（逐镜改提示词后一键投递）→ 图/视频/配音 链内自动连跑
S5 任务中心实时看进度（SSE）
S6 质检结果 → ✋门3
S7 一键合成成片 → 在线播放
S8 导出 / 继续改（局部重跑循环）
```

### 逐步骤明细（标注现有接口/页面，【新增】为缺口）

**S1 打开首页**（现状保留）
- 页面：`client/src/pages/AgentStudio/AgentStudio.tsx` hero 模式。
- 交互：一句话输入 / 模板灵感剧场 / 风格中心深链。首次用户若无 Provider 配置，输入框上方显示引导横幅（【新增·前端】读 `GET /api/providers` 判断空配置，火宝式"横幅自动消失"）。

**S2 开拍计划门**（现状保留 + 小改）
- 组件：`AgentStudio.tsx` renderPlanGate。改法：确认按钮拆成「先生成大纲预览」（只跑 script 技能，不物化不建图）与「直接开拍」。
- 接口：现有 `POST /api/projects/quick-create`（`server/modules/projects/projects.controller.ts` L51）。【新增·后端】`POST /api/projects/preview-outline`：只调 `StorySkillsService.runSkill({kind:'one_sentence_expand'})` 返回大纲文本，不建项目。

**S3 流水线总控页（新页面，对标火宝剧集工作台 + DramaClaw 步骤页）**
