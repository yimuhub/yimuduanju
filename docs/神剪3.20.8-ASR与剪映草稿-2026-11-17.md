# 神剪 3.20.8 · ASR 适配层与剪映草稿导出

日期：2026-11-17  
分支：`feature/shenjian-delivery-v3.20`  
基线：`v3.20.7`

## 为什么做这两个节点

对标报告 P1 里，真正影响“商业可交付”的两块是：

1. **无字幕素材对 Agent 是黑箱**：没有 ASR，只能靠镜头对白/字幕，所谓“通读 30 分钟再剪 1 分钟”不成立；
2. **成片只能在神剪里继续改**：不能把工程交回剪映，客户已有的剪映工作流接不上。

本轮把这两块补上，并保持“不复制火宝/ArcReel 的受限代码，只重写方法”。

## 1. ASR 适配层（`server/modules/timeline/asr.service.ts`）

### 支持两种 provider

- **openai**：任何兼容 `POST /audio/transcriptions` 的服务（OpenAI / 火山 / 自建中转），
  环境变量 `YIMU_ASR_API_KEY` / `YIMU_ASR_BASE_URL` / `YIMU_ASR_MODEL`。
- **local**：本机 `whisper` / `faster-whisper` / `whisper-cli`，环境变量
  `YIMU_WHISPER_BIN` / `YIMU_ASR_MODEL`。

未配置时返回 503，前端直接提示“缺密钥或 whisper”，不假装转写成功。

### 只转当前片段，不整片重转

- 从 EDL 取片段 `inPoint / outPoint`；
- `materializeMediaToFile` 统一读取 `/uploads`、资产代理、公网 URL；
- ffmpeg 抽 16k 单声道 WAV，再交给 provider；
- 段落时间加回 `inPoint`，写 `timeline_clips.transcript`（迁移 0036），不改时间线版本。

### Agent 索引优先读 ASR

`shared/transcript-index.ts` 新增 `source='asr'`：

- 时间码按 `timelineStart + (seg.start - inPoint) / speed` 换算成成片毫秒；
- 同一镜已有字幕时不再重复；
- 没有字幕的素材，ASR 段落直接进入 `formatTranscriptForAgent`，粗剪选段不再只看开头。

前端属性条新增「语音转写」按钮，选中画面/音频即可转写；已转写显示段数。

## 2. 剪映草稿导出（`shared/jianying-draft.ts` + `jianying-draft.service.ts`）

- 生成 `draft_content.json` / `draft_meta_info.json` / `draft_virtual_store.json` / `Resources/`；
- 顶层 `version=360000`、`new_version=110.0.0`，视频/音频/字幕三类轨；
- 复合片段先展开；每个 segment 的 `material_id`、`extra_material_refs` 都能在 `materials` 中找到；
- 媒体路径用 `##_draftpath_placeholder_<draftId>_##/Resources/...`，换机器后由剪映自动改写；
- 字幕写 `materials.texts[].content` 的 JSON（`text + styles + range + font`），不是裸字符串；
- 打包优先用系统 `zip`（流式低内存），无 `zip` 时退回纯 Node store ZIP，但限制 256MB；
- 前端顶栏「剪映草稿」按钮走 POST + CSRF，拿到 Blob 后触发下载，避免 GET 被 CSRF 拦截。

## 4. 边界（必须如实说）

- **没有在剪映客户端里打开验证**：本机未安装剪映，无法证明每个剪映版本都能导入；
  结构按 360000/110.0.0 与开源实现字段对齐，已通过引用链自检。
- **运镜关键帧不写入草稿**：剪映 `common_keyframes` 字段方言未逐版本验证，宁可不写，
  也不写出“能导入但效果错”的假关键帧。
- **ASR 的词级时间戳**取决于 provider：OpenAI `verbose_json` 给 segment 级；
  本机 whisper 给 segment 级；没有强制词对齐。
- **Agent 仍是单轮提案 + 前端确认应用**，不是模型多轮工具循环；下一节点再做
  `read_timeline / scan_issues / list_revisions / apply_ops` 工具化。
- **阶段账本与失效传播**仍未落库；这是下一节点。
