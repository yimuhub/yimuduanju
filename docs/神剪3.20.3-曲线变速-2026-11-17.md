# 神剪 3.20.3 · 曲线变速

## 实现方式
剪映的曲线变速是连续速度曲线；当前浏览器预览与 ffmpeg 导出共用「单段匀速」模型。为了让功能真实落地而不是假面板，本节点用**等长源片段 + 逐段速度**的折线逼近：

- `setClipSpeedCurve(id, speeds[])` 把选中画面按源时长等分成 N 段，每段生成一个真实 `TimelineClip`，各自设置速度。
- 段与段首尾相接，后续同轨片段按总时长差 ripple 平移；原片段删除，整组操作一次提交、一次撤销。
- 拆出的片段可继续裁剪、拖动、转场、导出，走原有 EDL/导出链路，没有第二套速度模型。
- 应用曲线时原片段的运镜关键帧不保留（可见时间重新计时），面板明确提示。

## UI
- `Shift+B` 打开曲线面板；属性条也有「曲线变速」按钮。
- 预设：缓入缓出 / 子弹时间 / 快剪冲刺 / 慢镜头铺陈。
- 3–7 段滑杆 + 数值输入，实时显示每段可见时长与总时长；可增删段。
- 应用后 toast/撤销由 EDL 统一处理。

## 边界
- 这是折线逼近，不是剪映那种连续贝塞尔速度曲线；段数越多越平滑。
- 目前只作用于画面片段；音频片段没有速度属性，保持原速。
