## 一、平台总览与用户角色

本平台是面向 **AI 短剧 / AI 漫剧 / AI 广告片** 的一站式生产系统。核心理念：**对话即创作**——你用一句话开拍，系统把创意拆成可确认的计划，再沿流水线自动完成剧本 → 人物场景 → 分镜 → 出图 → 视频 → 配音 → 合成 → 质检。

| 用户角色 | 典型场景 | 主要使用界面 |
|---|---|---|
| **创作者（核心用户）** | 从创意到成片的全流程生产 | 极客模式三栏工作台、自由画布、流程总控 |
| **工作室主理人（重度用户）** | 多项目并行、批量生成、成本管控 | 数据看板、任务队列、分镜、导出、画布 |
| **运营/管理员** | 供应商配置、预算档、计费核对 | 设置、用户中心、看板费用区 |
| **初次使用者（小白）** | 零门槛产出第一部作品 | 极简开拍首页、灵感剧场、一键创作 |

平台提供**两种界面模式**，随时切换、刷新保持：
- **极客模式**（默认）：左=会话栏，中=对话流，右=功能标签栏（类似浏览器开页签，功能页在右栏打开、聊天不中断）。三栏宽度可拖拽调整。
- **经典模式**：左侧可折叠菜单 + 整页导航 + 任务/资产/动态助手坞。适合习惯传统后台系统的用户。
- 切换方式：极客模式左栏用户卡旁「经典模式」按钮 / 经典模式侧栏底部「极客模式」按钮 / ⌘K 命令面板首位。

## 二、快速上手：三步出第一条成片

1. **配置模型供应商（仅首次）**：进入「设置 → 供应商」，点「新手一键预设模板」选择通道（火山方舟/硅基流动/OpenAI），粘贴 API Key，点「测试连通」确认可用。没有 Key 也可用内置「本地免 Key 演练沙盒」体验全流程。
2. **一句话开拍**：在作战室首页大输入框输入创意（如"深夜便利店，店员捡到一只会说话的猫"），或在「灵感剧场」点一张模板卡直接开拍。截图：`01-极客作战室-开拍入口.png`
3. **确认计划 → 等成片**：弹出「开拍计划」卡（可改单集时长/画风/画幅/预算档），点「🎬 开拍」；剧本生成后点「剧本门：去确认」→ 分镜门「通过」→ 之后图片/视频/配音/合成自动连跑，右侧产出面板与画布实时更新，最终「终审通过」项目就绪，到「导出」页合成 MP4。

> 全程只有三道人工确认门（剧本/分镜/终审），其余全自动；每个任务的进度、失败原因都在任务列表和画布节点上实时可见。

## 三、极客模式工作台（创作者主界面）

截图：`01-极客作战室-开拍入口.png`、`02` 系列同页、`10-工作台-流程总控.png`

- **左栏（会话栏）**：「+ 新对话 ⌘N」、会话搜索、会话列表（进行中/更早分组）；底部**功能网格**——点击任意功能（数据看板/我的项目/风格中心/模板中心/资产库/AI助手/用户中心/设置）会在**右栏以标签页打开**，聊天不中断；底部用户卡显示昵称与在线状态。
- **中栏（对话栏）**：与 Agent 对话执行一切创作动作；顶部页签可切「对话/任务/产出视图」；支持 @ 引用、附件上传（图片即时预览、剧本文本自动提取）。
- **右栏（功能标签栏）**：「产出」为固定首签（内含 产出资产/生成任务/活动轨迹 三个子视图）；点 + 号或左栏网格可再开 功能页签，页签可切换/关闭。
- **三栏拖拽**：栏间分隔条可拖动调宽（双击复位，宽度本地记忆）。
- **⌘K 命令面板**：搜索功能与会话，回车直达；首位是模式切换。

## 四、各功能模块详解

### 4.1 数据看板（运营/主理人）
截图：`03-数据看板.png`
KPI 四卡（项目/镜头/资产/累计费用）+ 生成任务实时列表（进度条、失败原因直出）+ 最近项目行式列表 + 全站动态时间线。5 秒自动刷新。顶部问候语显示流水线实时状态（"N 个任务正在生成 · 今日完成 M"）。

### 4.2 我的项目（全部用户）
截图：`04-我的项目.png`
行式列表：状态徽章（草稿/资产生成中/分镜就绪/成片中/完成/失败）+ 封面缩略图 + 相对时间；hover 出现 打开/画布/删除 操作；顶部搜索、状态筛选、排序；空状态引导回作战室开拍。

### 4.3 一键创作（小白首选）
截图：`05-一键创作.png`
三栏向导：左=模式选择（极速/剧本/专业导演）+ 步骤 1-2-3；中=当前步内容；右=实时参数摘要 + 费用预估 + 「开始生成」常驻按钮。

### 4.4 风格中心
截图：`06-风格中心.png`
22 种主流画风（真人短剧/漫剧动漫/国风水墨/3D 写实/赛博朋克五大类），每风格含正/负提示词与适用产品线；点卡片看详情，提示词一键复制，「以此风格开拍」直达作战室并自动带入。

### 4.5 模板中心
截图：`07-模板中心.png`
题材/时长/形态分类筛选，每模板含封面、时长、画幅、使用次数；「使用模板」直接进入开拍流程；支持新建/编辑/删除（hover 卡片右上角）。

### 4.6 资产库
截图：`08-资产库.png`
全平台产出素材的统一库：类型/项目/关键词筛选 + 排序；卡片 hover 预览/下载；点开大图弹窗支持 ←/→ 切换、Esc 关闭、显示归属项目；空状态双引导。

### 4.7 AI 助手
截图：`15-AI助手.png`
60 个内置技能的启停面板（按短剧/漫剧/广告/通用分组）+ 对话区。技能开关即时生效（失败自动回滚）。

### 4.8 用户中心与会员
截图：`16-用户中心.png`
个人资料（昵称可编辑，全站同步）、金色会员卡与权益、真实用量统计（本月费用/任务数/预算进度）、三档套餐（升级按钮为商业化预留）、快捷设置入口。

### 4.9 设置（运营/管理员）
截图：`17-设置.png`
左侧锚点导航（供应商/模型绑定/计费/偏好，窄容器自动收起）+ 顶部状态卡（已配供应商数/模型覆盖/预算档）。供应商行式列表：测试连通真实调用、多 Key 轮换管理、新手预设模板、启停开关。

## 五、项目工作台（生产核心）

进入任一项目后，左侧为分组竖导航（概览/流程总控/剧本圣经/美术资产/镜头/画布/交付），顶部为项目名+状态徽章+「流程总控」主按钮。

| 模块 | 说明 |
|---|---|
| **流程总控** | 九段流水线可视化（题材→剧本→人物场景→分镜→首帧→视频→配音→合成→质检），当前段高亮；三道确认门在此通过；配套任务与画布互跳入口。截图：`10-工作台-流程总控.png` |
| **剧本** | 剧本全文与解析状态，物料化入口。截图：`11-工作台-剧本.png` |
| **圣经/人物/场景** | 世界观设定集：人物 LOCK 锚点与衣橱、场景连续性锁、道具状态 |
| **分镜** | 分镜卡片列表：逐镜提示词行内编辑、保存并重跑首帧、失败重试。截图：`12-工作台-分镜.png` |
| **导演台 / 时间线** | 镜头参数与多轨编排；时间线支持收起/展开（头部按钮/右缘把手/⌥T） |
| **资产** | 项目内素材管理 |
| **AI 助手（项目）** | 8 个项目智能体（导演/剧本/分镜/角色/场景/摄影/剪辑/质检），人设与技能来自注册表 |
| **任务队列** | 项目全部生成任务：SSE 实时进度、「重试全部失败」聚合 |
| **质检** | QC 报告、一键重跑失败镜头 |
| **导出** | 成片合成（MP4）、剪映草稿、SRT/ASS 字幕、发布文案包。截图：`14-工作台-导出.png` |

## 六、自由画布（可视化创作主体）

截图：`13-自由画布.png`
- **11 类节点**：文本/图片/视频/音频/导演/剧本/角色/场景/分镜/备注 + 连线即引用（生成时自动注入上游参考）。
- **真实生成**：双击节点或拖线发起生成，产物自动回填节点；无主产物自动落新节点并连线。
- **交互**：双击空白建文本节点、右键菜单（重命名/复制/设为参考/删除）、Delete 删除、⌘D 复制、框选批量、小地图+缩放控件、一键铺开（DAG 整理）。
- **画布 AI 助手**：右下悬浮面板，四工种人设（导演/编剧/美术/质检），@ 引用节点，回复一键落地为节点。
- **集数切换**：顶栏第 1/2/3 集分存。
- **「分镜上画布」**：底部栏一键把项目分镜拉成竖排流水线节点（幂等）。
- **3D 导演台**：标准 three.js 编辑器交互——OrbitControls 平滑旋转视角（右键平移/滚轮缩放）、单击选中角色、官方变换手柄拖动排位、运镜预设一键摆机位、白模/九宫格辅助线、录制序列；顶栏「← 退出导演台」随时返回。

## 七、常见问题（FAQ）

- **开拍后在哪里看进度？** 极客模式右栏「产出 → 生成任务」、数据看板任务列表、项目工作台「流程总控」/「任务队列」，四处同步实时。
- **生成失败怎么办？** 任务列表与画布节点都会显示上游原始错误；「重试全部失败」一键重跑；供应商配置问题去设置页「测试连通」。
- **两模式的界面会互相影响吗？** 不会，模式与各自布局状态独立记忆。
- **图片/视频版权？** 全部产物由你配置的模型服务生成，存储在你本地（本地部署形态）。
- **忘记保存？** 画布与会话状态自动持久化；项目数据实时落库。
