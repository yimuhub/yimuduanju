# 一幕·YIMU AI 短剧创作平台 · 功能列表

> 本平台是一站式 AI 短剧 / AI 漫剧工业化生产平台，从一句话创意到成片全流程自动化。
> 本地运行地址：`http://localhost:5173/app/yimu/`

---

## 一、总体架构

| 层级 | 技术 | 说明 |
|---|---|---|
| 前端 | React 19 + Vite 7 + Tailwind CSS 4 + shadcn/Radix | 10 个页面，响应式布局（含移动端抽屉导航），浅色主题；画布路由懒加载 + 路由级错误边界 |
| 后端 | NestJS 10 + Drizzle ORM | REST API，端口 3000 |
| 数据库 | PostgreSQL 16 | 11 张业务表 + 平台复合类型 |
| 本地网关 | Node.js（scripts/gateway.js） | 伺服前端产物 + 转发动态请求 + 注入用户身份 + 数据补全，端口 5173 |

## 二、页面与功能清单

### 1. 工作台（Dashboard）· `/app/yimu/`
- **品牌 Hero 区**：徽章「一幕·YIMU AI 短剧创作平台」、主标语「让 AI 拍一部好剧」、副文案、`开始创作` / `了解更多` 按钮、AI 自动生成竖屏预览图（90s·竖屏）
- **创作模式三选一**：
  - 极速模式：一句话全自动 90 秒短剧
  - 剧本模式：上传完整剧本，AI 智能解析分镜/人物/场景
  - 专业导演模式：全参数可控
- **创作统计**：项目总数、生成镜头数、资产总数、总费用、进行中任务、今日完成
- **最近项目**：最近 4 个项目（标题、时长、状态、更新时间）
- **热门模板**：模板中心前 6 个（按使用热度）

### 2. 我的项目（Projects）· `/app/yimu/projects`
- 项目列表 + 状态筛选（全部 / 草稿 / 制作中 / 已完成 / 失败）
- 项目卡片：标题、时长、状态标签、创建时间、缩略图
- 关键词搜索、分页
- `新建项目` 快捷入口
- 点击项目进入工作台

### 3. 一键创作（CreateWizard）· `/app/yimu/create`
- 三步流程：输入创意 → 参数设置 → 生成中
- 三种创作模式：极速 / 剧本（上传剧本）/ 专业导演
- 专业模式 6 参数真实透传：经 `quickCreate(professional)` 存入 `project.metadata`，
  由剧本物化消费（目标总镜头数/单镜时长/景别偏好/运镜风格/字幕开关；配音预设随任务记录）
- Key 门禁：无可用 Provider（已启用且配 Key）时提示去设置，不阻塞输入；
  无 Key 时任务排队等待，配置后消费器自动执行（`hasApiKey` 由后端如实返回，Key 本身永不落地前端）
- **参数设置**：
  - 时长：30s / 60s / 90s / 3min / 5min
  - 视频比例：9:16 竖屏 / 16:9 横屏 / 1:1 方形
  - 画风：写实仿真人 / 2D 日漫 / 韩漫 / 国漫 / 3D 国风 / 赛博朋克
  - 预算模式：质量优先 / 均衡 / 成本优先 / 速度优先
- 一句话创意输入（20-200 字）+ 实时字数统计
- 生成进度与预计时间（3-5 分钟）

### 4. 模板中心（Templates）· `/app/yimu/templates`
- 模板列表（内置种子模板：都市情感、古风仙侠等）
- 模板分类筛选、搜索（风格/时长为客户端过滤，后端暂不支持该参数）
- 模板详情弹窗：支持 `?template=<id>` 深链直达（Dashboard 热门模板入口）
- 一键使用：跳一键创作 `?templateId=` 自动预填时长/画幅/画风/题材/导演参数
- 失败展示空状态，不再用假数据冒充

### 5. 资产库（Assets）· `/app/yimu/assets`
- 素材资产管理（角色、场景、镜头等资产分类）
- 上传 / 检索 / 管理

### 6. AI 助手（AiAssistant）· `/app/yimu/ai-assistant`
- AI 对话助手，辅助创作（剧本构思、分镜建议等）

### 7. 设置（Settings）· `/app/yimu/settings`
- **API 通道管理（三通道）**：
  1. 火山方舟（volcengine_ark）：火山方舟大模型 / 即梦
  2. OpenAI 兼容中转站（openai_proxy）：自定义 baseURL + key
  3. 自定义（custom）：完全自配
- Provider 配置：文本模型、图片模型、视频模型、TTS 模型、音色、请求格式
- 默认 Provider 设置

#### 8.1 无限画布（核心新增）
- **节点系统**：项目 / 场景 / 镜头 / 角色 / 地点 / 备注 六类节点，带类型图标与渐变配色
- **画布操作**：滚轮以鼠标为中心缩放（0.3–2×）、空白拖拽平移、空格按住平移、Shift 拖拽框选多选、节点拖拽（锁定节点不可拖）
- **关系连线**：场景 → 镜头 SVG 虚线连线，随节点移动实时更新
- **自动布局**：一键排布——项目节点居中、场景横向排开、镜头纵向挂场景、角色左列、地点右列
- **布局记忆**：布局自动保存到本地（按项目隔离），下次进入自动恢复
- **工具栏**：放大 / 缩小 / 百分比 / 重置视图、自动布局、同步数据、添加备注、新建场景
- **@Agent 指令条**：自然语言指挥画布（本地规则引擎）——
  - 「第 N 场 重设计成 XX 风格」→ 更新场景摘要
  - 「所有镜头改为 50mm / 改为特写」→ 批量改全部镜头焦段/景别
  - 「第 N 场的所有镜头改为俯拍」→ 按场批量改机位
  - 其他指令 → 给出规划建议回复
- **节点详情面板**：锁定/解锁、缩略图、评论、按类型快捷跳转（生成图/生成视频/打开角色库等）
- 键盘：Esc 取消选择

#### 8.2 导演台（三栏工作台）
- 左栏**项目树**：场景可展开收起，列出每个镜头
- 中栏**实时监看**：当前镜头画面 / 画面描述 / 对白情绪，一键生成图片 / 视频 / 锁定
- 右栏**导演控制**：景别（6 选）、机位角度（6 选）、焦段（24–135mm）、运镜（9 选），点击即保存
- 底部**镜头流色块**：全片镜头总览，选中高亮、已生成绿色
- 顶部「打开无限画布」入口

#### 8.3 时间线（多轨道）
- 5 条轨道：视频 / 对白 / BGM / 音效 / 字幕
- 镜头 clip 按时长等比排布（秒刻度），视频轨显示缩略图
- 点击选中、双击跳分镜页、**拖动右边缘调整镜头时长（真实保存）**
- 底部选中镜头详情条 + 智能剪辑助手横幅

### 9. 其他
- 404 页面（NotFound）
- 全局侧边栏：Logo（渐变方块 + 一幕·YIMU AI 短剧创作平台）、7 个导航、底部用户卡（一幕用户 / 专业版）
- 顶部栏：首页导航、全局搜索（项目/资产/模板）、通知、用户头像

## 三、后端 API 模块

| 模块 | 路径 | 能力 |
|---|---|---|
| projects | `/api/projects` | 项目 CRUD、快速创建、进度（PATCH status 受状态机转移白名单约束） |
| dashboard | `/api/dashboard` | 统计、费用汇总、运维指标（metrics：状态分布/24h 成功率/平均耗时） |
| templates | `/api/templates` | 模板列表（搜索/分页/使用量排序）/ 详情 / 按类型 / 使用打点 / 项目存为模板 |
| assets | `/api/assets` | 资产（项目列表/上传/创建；写操作支持 `projectId` 归属约束）|
| providers | `/api/providers` | Provider 配置管理（火山方舟/中转/自定义/官方直供；official 禁止手工创建；多 Key 增删/激活，生效 Key 优先于主 Key 列）|
| generation | `/api/generation` | 生成任务创建/列表/重试/取消/轮询（成功按档位结算并累加项目成本；BullMQ 消费器自动执行，Redis 缺失降级进程内） |
| agents | `/api/projects/:id/agents` | 智能体消息（列表/发送/清空，持久化）|
| storyboard | `/api/projects/:id/storyboard` | 分镜（场景/镜头 CRUD + 生成图/视频/配音/批量/剧本解析；图视频自动注入角色参考图；`adapt-novel` 小说转剧本 / `rewrite` 深度改造走剧本技能任务）|
| story-skills | `/api/story-skills` | 技能清单 + 风格预设（`novel_to_script` / `script_rewrite` / `one_sentence_expand`，版本化；10 种风格含真人实景，visual/negative 直拼生成提示词） |
| bible | `/api/projects/:id/bible` | 世界观 / 风格圣经 / 角色 / 地点；标准描述一键补全 |
| qc | `/api/projects/:id/qc` | 质检报告（规则检 + 逐镜一致性检查）/ 一键重跑问题镜头 |
| export | `/api/projects/:id/export` | 真实交付物下载：字幕 SRT / 分镜 JSON / 导出清单 / 剪映草稿（实验性，三轨 draft）；成片 MP4 在浏览器端用 FFmpeg.wasm 合成（零服务端成本）；导出页含交付就绪检查 |
| billing | `/api/billing` | 价格表公开查询/调价、官方通道配置（Key 只写）、生成前预估；结算唯一可信源 |
| admin | `/api/admin`（需 x-admin-token） | License 状态、SSO 状态、审计日志查询 |
| view | `/` | HTML 渲染 |

> **输入校验**：上述写接口与分页查询已接 class-validator DTO（非法直接 400），见各模块 `dto.ts`；全局管道为 transform + 隐式转换（无 whitelist，未知字段透传）。
>
> **任务消费器**（`generation/job-worker.service.ts`，随后端启动，`JOB_WORKER_ENABLED=false` 关闭）：
> 生产者认领 pending → BullMQ 队列（`JOB_WORKER_CONCURRENCY` 并发，默认 2）→ 真实调用网关 → 回写目标 → 成功按档位结算/失败重试；
> Redis 缺失自动降级进程内串行；启动回收崩溃残留；超预算暂停认领。
> `parse_script` 启发式物化（消费项目专业参数：镜头数/时长/景别/运镜/字幕开关），状态沿 parsing → planning → storyboard_ready 推进。
> 未配置 Provider 时任务保持 pending 等 Key，不消耗重试。
>
> **智能路由**：项目预算模式 → 价格档位（quality→旗舰/cost→极速/balanced-fast→均衡）；
> 官方通道启用且有 Key 时优先，决策理由记日志；结算单价=档位价。
>
> **企业版**：见 [docs/企业版部署.md](企业版部署.md)（compose 一键栈 + License + 管理接口 + 审计）。
>
> **月度预算上限**（零迁移）：`MONTHLY_BUDGET_CAP_CNY` 环境变量，未设置即不限；
> 10 处任务创建入口统一守卫，超限 400 拒绝；消费器超限暂停认领；`cost-summary` 透出 `budgetCap`。

> **本地网关补全接口**（云端后端缺失，本地环境层补齐，不改云端源码）：
> - `GET /api/projects/:id` 项目详情（后端缺 @Get(':id')）
> - `GET /api/projects/:id/storyboard/scenes/:sceneId/shots` 按场景查镜头（前端 listShots 走嵌套路由）
> - `GET /api/dashboard/recent-projects | activity | usage-trend` 仪表盘数据

## 五、三大 API 对接通道

| 通道 | ProviderType | 适用场景 | 配置项 |
|---|---|---|---|
| 火山方舟 | `volcengine_ark` | 火山方舟大模型 / 即梦视频 | API Key、文本/图片/视频/TTS 模型、请求格式 volcengine_ark |
| OpenAI 兼容中转站 | `openai_proxy` | 自建或第三方中转 | baseURL、API Key、模型名、格式 openai |
| 自定义 | `custom` | 任意兼容端点 | 完整自定义 |

每个 Provider 支持：文本模型（剧本/文案）、图片模型（分镜/角色/场景图）、视频模型（成片）、TTS 模型 + 音色（配音）。

## 六、平台数据流（一句话到成片）

```
一句话创意
   ↓ 极速模式 / 剧本上传
剧本生成（文本模型）→ 剧本解析
   ↓
世界观/角色/场景生成（文本+图片模型）
   ↓
分镜生成（分镜表 + 参考图）
   ↓
镜头生成（图片模型 → 视频模型）
   ↓
配音（TTS 模型 + 音色）
   ↓
剪辑合成 → 质检 → 导出成片
```

### 7.1 对标依据（多平台融合）
- **Pavo（主参照）**：①左侧「画布元素」列表 + 中央无限画布 + 右侧对话；②**节点即工具箱**——点击不同节点弹出该类型专属 Agent 工具；③**分支创作**：从上游节点拉子节点，旧版本保留对比；④**资产固化**：角色四视图 / 场景设定图固化为资产跨镜头引用；⑤**3D 导演台**：角色素体摆位 + 机位（低/高/侧拍）+ 导演/相机视角 + 导出站位示意图；⑥一键铺开（故事 → 剧本 → 角色/场景资产自动拆解）。
- **小云雀（协同）**：对话 @ 引用全画布资产；多会话标签页并行；创意助手（热点检索/爆点解析/选题推荐/方案输出）；资产-画布-对话三方联动。
- **即梦（手感）**：双击画布空白加节点；点击节点弹 AI 工具。
- **Toonflow（组织）**：集切换（每集独立画布/持久化）；一键整理自动布局；右侧对话助手。

### 7.2 功能清单（v5 已交付）
