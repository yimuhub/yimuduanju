# 一幕·YIMU AI 短剧创作平台

> 从一句话创意到成片，AI 短剧 / AI 漫剧全流程自动化生产平台。
> **本地工程基于云端基线 + 本地增强补丁**（项目工作台新增画布/导演台/时间线等 Tab，后端新增 `pavo3` 通用生成代理，本地网关补齐云端缺失的仪表盘/详情接口）。
> 补丁清单见 [docs/功能列表.md](docs/功能列表.md) §三（本地网关补全接口）与 §七/§八（画布 v5 / 自由画布）。

## ✨ 核心能力

- **三大创作模式**：极速模式（一句话 → 90s 短剧）、剧本模式（上传剧本 → 智能解析）、专业导演模式（全参数可控）
- **全流程自动化**：剧本 → 世界观 → 角色/场景 → 分镜 → 镜头生成 → 配音 → 剪辑 → 质检 → 导出
- **三种 API 通道**：火山方舟、OpenAI 兼容中转站、自定义 API
- **AI 短剧 + AI 漫剧**：6 种画风（写实仿真人 / 2D 日漫 / 韩漫 / 国漫 / 3D 国风 / 赛博朋克）
- **多智能体项目工作台**：14 个标签页（概览/无限画布/剧本/圣经/人物/场景/分镜/导演台/时间线/资产/AI助手/任务/质检/导出…）
- **无限画布**：项目全貌可视化编排 —— 节点拖拽/缩放/框选/自动布局/@Agent 自然语言指令
- **导演台 + 多轨道时间线**：三栏导演工作台、按帧轨道剪辑
- **8 种项目 AI 智能体**：对话真实持久化，覆盖剧本/分镜/角色/场景/摄影/剪辑/质检

## 🚀 旗舰能力

- **无限画布 v5**：项目全貌可视化编排——项目 / 场景 / 镜头 / 角色 / 地点 / 备注六类节点，滚轮缩放、拖拽平移、框选多选、自动布局（布局记忆按项目隔离）；@Agent 自然语言指令条（如「所有镜头改为特写」批量改机位）、节点详情面板快捷跳转生成图/视频。
- **导演台**：三栏导演工作台——左栏项目树（场景展开收起）、中栏实时监看（当前镜头画面 / 画面描述 / 对白情绪，一键生成图片 / 视频 / 锁定）、右栏导演控制（景别 6 选、机位角度 6 选、焦段 24–135mm、运镜 9 选，点击即保存）；底部镜头流色块总览全片进度。
- **多轨道时间线**：视频 / 对白 / BGM / 音效 / 字幕 5 条轨道，镜头 clip 按时长等比排布（秒刻度，视频轨显示缩略图）；拖动右边缘调整镜头时长真实保存，双击跳分镜页。
- **计费与成本**：价格表公开查询、生成前费用预估、官方通道配置、月度预算上限（`MONTHLY_BUDGET_CAP_CNY`）；生成成功按档位结算并累加项目成本，账单在工作台统计区实时可见。
- **导出交付**：字幕 SRT / 分镜 JSON / 导出清单真实下载；剪映草稿（实验性，三轨 draft）一键带出；成片 MP4 在浏览器端用 FFmpeg.wasm 合成（零服务端成本），导出页含交付就绪检查。
- **自由画布**：pavo3 通用生成代理，文本 / 图片 / 视频 / 音频三通道 API 真实接入（从「设置 → 模型服务」取供应商配置）；未配置或后端不可达时自动降级为演示数据并明确标注，不冒充真实产物。

## 📦 安装

四种形态，任选其一：

| 形态 | 命令 / 产物 | 需要预装什么 |
|---|---|---|
| **桌面客户端**（推荐给创作者） | `YIMU_3.7.3_*.dmg` / `*-setup.exe` / `*.AppImage` | **什么都不用装**（包内自带 Node + PostgreSQL + ffmpeg） |
| **Docker 单容器**（自带数据库） | `docker run -d -p 127.0.0.1:5173:5173 -v yimu-data:/data yimuhub/yimuduanju:3.7.3` | 只需要 Docker |
| **Docker 三容器**（app + PG + Redis） | `docker compose up -d --build` | Docker + Compose |
| **源码安装** | `bash scripts/install-macos.sh` / `install-linux.sh` / `install-windows.bat` | Node 22 + PostgreSQL 16 |

桌面端与单容器镜像的差异、数据目录、构建方式与排障见
[docs/桌面客户端与Docker分发.md](docs/桌面客户端与Docker分发.md)。
源码安装的详细步骤见 [docs/安装指南.md](docs/安装指南.md)。

## 🚀 快速开始（源码 / macOS）

```bash
# 1. 前置依赖
brew install postgresql@16
brew services start postgresql@16

# 2. 首次赋权（只需一次）
chmod +x scripts/start.command

# 3. 启动（方式一：双击 scripts/start.command；方式二：终端）
./scripts/start.sh
```

浏览器自动打开：**http://localhost:5173/app/yimu/**

## 🔒 默认只听本机

网关默认绑定 `127.0.0.1`，`/api/*` 没有登录鉴权（本地单用户，身份由网关注入）。
监听非回环地址会被拒绝启动，确需局域网/容器访问必须显式设置 `YIMU_ALLOW_LAN=true`；
Docker 端口只发布到宿主回环，企业版用 `SERVER_BIND_HOST` 显式放开。

## ⚠️ 注意事项

- 必须通过 **`/app/yimu/`** 前缀访问（与云端一致的路由 basename），否则白屏
- 生成任务需先在「设置」配置有效的 API 通道（火山方舟 / 中转站 / 自定义）
- 数据持久化于本地 PostgreSQL 库 `yimu`
