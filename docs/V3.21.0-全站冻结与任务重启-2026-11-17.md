# V3.21.0 全站冻结与任务重启

## 新增
- `POST /api/queue/jobs/pause-all`：排队任务全部暂停、执行中任务终止，同时打开全站消费暂停。
- `POST /api/queue/jobs/:id/restart`：已终止 / 失败 / 暂停的任务一键重启，重新进入排队。
- 队列页新增「全部冻结」按钮；终止 / 失败任务行新增「重启」按钮；暂停行保留「恢复」。
- 恢复与重启都走现有 `retryJob` / `resumeJob`，不新建项目、不重复拆任务。

## 边界
- 执行中的任务无法冻结线程，只能终止；终止后可用「重启」恢复。
- 全站消费暂停仍是进程级；如进程重启，需再点一次「暂停全站消费」。
