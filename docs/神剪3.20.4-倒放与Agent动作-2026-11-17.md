# 神剪 3.20.4 · 真倒放与 Agent 动作扩展

## 倒放
- 数据：`timeline_clips.reverse BOOLEAN`（迁移 `0034_timeline_clip_reverse.sql`），读回 / 保存 / DTO 全链路。
- 预览：画面按 `outPoint - 本地时间×speed` 反向定位；浏览器不支持负速率，倒放时保持暂停，由主时钟逐帧反向 seek。
- 导出：视频链首加 `reverse`；独立音频轨加 `areverse`，再接音量与 adelay。
- UI：属性条「倒放 / 取消倒放」，选中态高亮；画面与音频都可用。
- ffmpeg 实测：`reverse,scale=...` 可正常编码。

## 对话直剪扩展
`shared/timeline-ops` 新增两条原子动作：
- `reverse(target, value)`：Agent 直接切换倒放。
- `keyframes(target, frames[])`：Agent 直接写运镜关键帧；服务端归一化，音频片段拒绝。
两条都进 dry-run diff、事务落库、审计与撤销；Agent 协议文本同步。

## 边界
- 倒放预览是逐帧反向 seek，拖动播放头流畅；连续播放时 CPU 占用高于正放。
- 倒放只反画面，不自动反转已分离的独立音频；需要时对音频片段单独开启倒放（剪映同语义）。
