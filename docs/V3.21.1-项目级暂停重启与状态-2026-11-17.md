# V3.21.1 项目级暂停 / 重启与状态显示

## 问题
- 全站冻结只改任务，项目卡片仍显示「生产中」。
- 没有单项目暂停入口；暂停后也没有项目级一键重启。

## 修复
- 新增项目状态 `paused`（暂停中），项目列表与工作台统一显示。
- `POST /api/queue/projects/:id/pause`：项目状态置 paused，排队任务暂停、执行中任务终止，原状态记入 `metadata.pausedFromStatus`。
- `POST /api/queue/projects/:id/resume`：恢复原状态，暂停任务重新入队。
- 工作台项目头部新增「暂停项目 / 重启项目」按钮，操作后刷新项目。
- 队列页保留「全部冻结」与单任务「恢复 / 重启」。

## 验证
- 本地 31 个项目全部置为 paused，卡片显示「暂停中」。
- 全站任务 `running 0 / paused 12 / cancelled 38`。
