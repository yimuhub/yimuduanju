# 一幕·YIMU AI 短剧工坊企业版部署说明（W6 1.0）

## 一、一键启动（Docker Compose）

```bash
# 1. 准备环境变量
cp .env.enterprise.example .env.enterprise
# 按需修改：DB_PASSWORD / ENTERPRISE_ADMIN_TOKEN / ENTERPRISE_LICENSE / LICENSE_SECRET
# （均为 compose 栈专用变量，示例文件「Docker Compose 企业栈」一节有中文说明；
#  单机部署请改通用字段：DATABASE_URL / ADMIN_API_TOKEN / YIMU_KEY_SECRET）

# 2. 启动
docker compose -f deploy/docker-compose.yml --env-file .env.enterprise up -d --build

# 3. 访问
# http://localhost:3000/app/yimu/（后端直服，含前端产物）
```

> 说明：本地开发继续用 `./scripts/start.sh`（PostgreSQL+Redis 本机模式）；
> 企业交付用本 compose 栈（postgres:16 + redis:7 + server），同仓不同配置，不分叉。

## 二、License（授权）

- 未配置 `ENTERPRISE_LICENSE` 时为**社区模式**（功能全开，无商业授权）。
- 签发（供应商操作）：
  ```bash
  node -e "const {signLicense}=require('./dist/server/modules/admin/license.js'); console.log(signLicense({seats:50,expiresAt:'2027-09-01T00:00:00.000Z'}, 'YOUR_SECRET'))"
  ```
- 把输出填入 `ENTERPRISE_LICENSE`，`LICENSE_SECRET` 填签发密钥；`GET /api/admin/license`（需管理令牌）可查状态。

## 三、管理接口（默认锁定）

所有 `/api/admin/*` 需请求头 `x-admin-token: <ENTERPRISE_ADMIN_TOKEN>`；
未配置该变量时整体 401，不存在无保护的管理后台。

- `GET /api/admin/license` —— 授权状态
- `GET /api/admin/sso` —— SSO 配置状态（1.0 为配置桩）
- `GET /api/admin/audit-logs?page=&pageSize=` —— 审计日志（变更操作自动记录）

## 四、审计

全局 `AuditInterceptor` 记录所有 POST/PATCH/PUT/DELETE（body 只记顶层 key，不落 Key 与大文本），
写入 `audit_logs` 表（migration 0003）。审计表缺失时只告警、不阻塞业务。
